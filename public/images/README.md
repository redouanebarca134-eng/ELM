# صور الموقع

ضع صورك هنا بهذه الأسماء بالضبط حتى تظهر في الموقع:

| الملف | المكان | الاستخدام |
| --- | --- | --- |
| `public/logo.png` | مجلد `public` | شعار ELM (الرأس + التذييل) |
| `public/images/shilajit.png` | مجلد `public/images` | صورة منتج الشيلاجيت النقي |
| `public/images/slim-tea.png` | مجلد `public/images` | صورة منتج Slim Tea |

> ⚠️ انتبه: الشعار يوضع في مجلد **`public`** مباشرة (وليس `public/images`).
> صور المنتجات توضع في **`public/images`**.

## كيف تضيف الصور (من الهاتف أو الحاسوب، بدون أوامر)

1. افتح صفحة مستودعك على GitHub
2. ادخل إلى المجلد الصحيح (`public` للشعار، أو `public/images` للمنتجات)
3. اضغط **Add file → Upload files**
4. أعد تسمية الصورة بالاسم الصحيح من الجدول أعلاه **قبل** الرفع
5. اسحب الصورة أو اخترها، ثم اضغط **Commit changes**

بعد دقيقة، يُعاد نشر الموقع على Vercel وتظهر صورك الحقيقية تلقائيًا.

> يوجد حاليًا شعار مؤقت (`logo.png`) — استبدله بشعارك الحقيقي بنفس الاسم.
> خلفية قسم البطل تعمل بدون رفع أي ملف.
