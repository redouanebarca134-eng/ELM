# صور الموقع

ضع صور المنتجات هنا بهذه الأسماء بالضبط حتى تظهر في الموقع:

| الملف | الاستخدام | الصورة |
| --- | --- | --- |
| `public/images/shilajit.png` | صورة منتج الشيلاجيت النقي | صورة علبة الشيلاجيت |
| `public/images/slim-tea.png` | صورة منتج Slim Tea | صورة كيس Slim Tea |
| `public/logo.png` | (اختياري) شعار ELM الدائري — لاستبدال الشعار المدمج | الشعار الدائري |

## كيف تضيف الصور (من الهاتف أو الحاسوب، بدون أوامر)

1. افتح صفحة مستودعك على GitHub
2. ادخل إلى مجلد **`public`** ثم **`images`**
3. اضغط **Add file → Upload files**
4. اسحب صورك أو اخترها من جهازك
5. **مهم:** أعد تسمية كل صورة بالاسم الصحيح أعلاه قبل الرفع
   (`shilajit.png` و `slim-tea.png`)
6. اضغط **Commit changes**

بعد دقيقة، يُعاد نشر الموقع على Vercel وتظهر صورك الحقيقية تلقائيًا.

> خلفية قسم البطل (الصورة الكبيرة في الأعلى) والشعار يعملان بدون رفع أي ملف.
> أنت تحتاج فقط إلى رفع صورتَي المنتجين.
