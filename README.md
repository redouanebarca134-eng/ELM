# ELM — موقع شيلاجيت (Shilajit) للتجارة الإلكترونية

موقع تجارة إلكترونية احترافي لعلامة **ELM** الجزائرية للصحة الطبيعية، المنتج البطل هو **الشيلاجيت (شيلاجيت)**. يجمع الموقع بين صفحة هبوط بيعية ومتجر إلكتروني كامل، بالعربية وباتجاه RTL، مع الدفع عند الاستلام (COD).

## المزايا الرئيسية

- **عربي بالكامل + RTL** (`lang="ar"` و `dir="rtl"`) باستخدام أدوات Tailwind المنطقية (`ms-/me-/ps-/pe-/start/end`).
- **خطوط عربية**: Tajawal للعناوين، Almarai للنصوص.
- **تصميم متجاوب** mobile-first مع رسوم متحركة خفيفة عند التمرير (framer-motion).
- **سلة تسوّق** تُدار في حالة React (بدون localStorage).
- **الدفع عند الاستلام** + نموذج طلب مع التحقق من رقم الهاتف الجزائري وقائمة الولايات الـ58.
- **تأكيد عبر WhatsApp** برسالة معبأة مسبقًا تتضمّن ملخّص الطلب.
- **SEO**: وسوم meta و Open Graph بالعربية، favicon، صورة OG.

## التقنيات

Next.js (App Router) · TypeScript · Tailwind CSS · framer-motion · lucide-react

## الصفحات

| المسار | الوصف |
| --- | --- |
| `/` | صفحة الهبوط (الرئيسية) |
| `/product/[slug]` | صفحة المنتج التفصيلية |
| `/shop` | المتجر |
| `/cart` | السلة |
| `/checkout` | إتمام الطلب (COD) + تأكيد |
| `/about` | عن ELM |
| `/faq` | الأسئلة الشائعة |
| `/contact` | اتصل بنا |

## التشغيل

```bash
npm install
npm run dev      # وضع التطوير على http://localhost:3000
npm run build    # بناء الإنتاج
npm run start    # تشغيل الإنتاج
```

## إعدادات قابلة للتخصيص

في `src/lib/constants.ts`:

- `BRAND.whatsapp` — رقم واتساب بالصيغة الدولية (افتراضيًا `213555000000`، **غيّره إلى رقمك**).
- `BRAND.email`, روابط `socials`.
- `SHIPPING.home` / `SHIPPING.stopdesk` — رسوم التوصيل.

المنتجات في `src/lib/products.ts`، والولايات في `src/lib/wilayas.ts`.
